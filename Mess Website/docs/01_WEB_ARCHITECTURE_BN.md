# 01 — Web Architecture & Routes (Mess Website)

## 1. ওয়েব আর্কিটেকচার ওভারভিউ
Mess Website তৈরি হবে **Next.js (App Router)** দিয়ে। এটি সার্ভার ও ক্লায়েন্ট রেন্ডারিংয়ের সমন্বয়ে উচ্চ নিরাপত্তা ও পারফরম্যান্স নিশ্চিত করে।

```text
[ Browser Client (Desktop/Tablet/Mobile Web) ]
                     │
                     ▼
       Next.js App Router (Server Components & Actions)
         ├── Auth Middleware (HTTP-only Session Cookies)
         ├── Zod Validation Layer
         └── Dynamic Route Handlers
                     │
                     ▼
           Supabase Backend
         ├── PostgreSQL (RLS + Constraints)
         ├── Supabase Auth
         └── Supabase Storage (Receipts & Profile Images)
```

## 2. ওয়েবসাইটের জন্য সুনির্দিষ্ট রাউট স্ট্রাকচার
```text
/                              -> ল্যান্ডিং পেজ বা অটো রিডাইরেক্ট
/login                         -> ইমেইল/পাসওয়ার্ড লগইন
/forgot-password               -> পাসওয়ার্ড রিসেট
/onboarding                    -> নতুন মেস তৈরি অথবা ইনভাইট কোড দিয়ে জয়েনিং
/app                           -> মূল ড্যাশবোর্ড (সামারি কার্ডস, আজকের বাজার, কুইক অ্যাকশনস)
/app/members                   -> মেম্বার ডিরেক্টরি (সার্চ, ফিল্টার, নতুন সদস্য যুক্ত করা)
/app/members/[memberId]        -> নির্দিষ্ট সদস্যের বিস্তারিত ও স্টেটমেন্ট
/app/meals                     -> মিল ক্যালেন্ডার ও বাল্ক-এন্ট্রি গ্রিড (সবার মিল একসাথে এন্ট্রি)
/app/market-schedule           -> বাজার ক্যালেন্ডার ও ড্র্যাগ-অ্যান্ড-ড্রপ রিঅর্ডার
/app/accounts/deposits         -> জমার হিসাব (ক্যাশ/বিকাশ/নগদ/ব্যাংক)
/app/accounts/expenses         -> খরচের হিসাব ও ভাউচার আপলোড
/app/settlement                -> চলতি ও পূর্ববর্তী মাসের সেটলমেন্ট লিস্ট
/app/settlement/[yyyy-mm]      -> নির্দিষ্ট মাসের সেটলমেন্ট উইজার্ড (প্রিভিউ, লক, আনলক)
/app/reports                   -> মেসের পূর্ণাঙ্গ ও মেম্বারভিত্তিক রিপোর্ট জেনারেটর (PDF/PNG)
/app/settings                  -> মেস সেটিংস, মুদ্রা (BDT), ব্রেকফাস্ট ভ্যালু (0.5), থিম
/app/audit-log                 -> অডিট ট্রেইল (শুধু Owner ও Manager দেখতে পারবে)
```

## 3. মূল মডিউল ও কার্যপ্রণালী (Website Specific)
1. **বাল্ক মিল এন্ট্রি গ্রিড (Bulk Meal Entry Grid)**:
   - ম্যানেজাররা ডেসকটপ স্ক্রিনে এক্সেল-স্টাইলে মেসের সকল মেম্বারের সকাল, দুপুর, রাতের মিল একসাথে এন্ট্রি বা আপডেট করতে পারবেন।
2. **বাজার শিডিউল ম্যানেজার (Market Scheduler)**:
   - মেম্বারদের ক্রমানুসারে ড্র্যাগ-অ্যান্ড-ড্রপ করে বা সরাসরি তারিখ সিলেক্ট করে বাজারের দায়িত্ব বণ্টন।
3. **মাসিক সেটলমেন্ট উইজার্ড (Monthly Settlement Wizard)**:
   - মাসের সব খরচ ও মিল ক্যালকুলেট করে মিল রেট দেখানো।
   - প্রিভিউ দেখা -> ম্যানেজার কর্তৃক অ্যাপ্রুভাল -> পিরিয়ড `locked` করা।
4. **রিপোর্ট এক্সপোর্ট ইঞ্জিন (PDF & Image Generation)**:
   - সার্ভার-সাইড অথবা ক্লায়েন্ট-সাইড থেকে বাংলা ফন্ট সাপোর্টেড প্রিন্ট-রেডি লেআউট জেনারেশন।
