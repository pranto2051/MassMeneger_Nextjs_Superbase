# 06 — Test Plan & Quality Assurance (Mess Website)

## 1. গাণিতিক হিসাব ও ব্যালেন্স টেস্ট
- [ ] মোট মিল ও খরচের ভাগফল সঠিক হওয়া (যেমন: খরচ ১৮,০০০ টাকা, মোট মিল ৬০০ -> মিল রেট ৩০.০০ টাকা)।
- [ ] শূন্য মিল ($M_{total} = 0$) হলে যেন Divide-by-zero এরর না আসে।
- [ ] মেম্বারদের জমার সাথে মিল খরচের সমন্বয়ে ব্যালেন্স সঠিক আসা।

## 2. ব্রাউজার ও রেসপনসিভনেস টেস্ট
- [ ] Chrome, Safari, Firefox এবং Edge-এ লেআউট নিখুঁত থাকা।
- [ ] ডেসকটপ, ল্যাপটপ এবং ট্যাবলেটে সাইডবার ও গ্রিড টেবিলের সঠিক আচরণ।
- [ ] লাইট ও ডার্ক মোডে টেক্সট কন্ট্রাস্ট নিশ্চিত করা।

## 3. রিপোর্ট এক্সপোর্ট টেস্ট
- [ ] PDF ও PNG এক্সপোর্টে বাংলা যুক্তাক্ষর ভেঙে না যাওয়া।
- [ ] প্রিন্ট প্রিভিউতে আনওয়ান্টেড বাটন বা সাইডবার অদৃশ্য থাকা।
