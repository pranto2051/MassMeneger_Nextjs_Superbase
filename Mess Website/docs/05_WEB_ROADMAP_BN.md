# 05 — Implementation Roadmap (Mess Website)

## ফেজভিত্তিক বাস্তবায়ন রোডম্যাপ

### ফেজ ১: প্রজেক্ট ইনিশিয়ালাইজেশন ও অথেন্টিকেশন
- [ ] Next.js (App Router) + TypeScript + Tailwind CSS প্রজেক্ট সেটআপ।
- [ ] Supabase ক্লায়েন্ট (SSR কুকি হ্যান্ডলার সহ) কনফিগারেশন।
- [ ] লগইন, সাইনআপ, পাসওয়ার্ড রিসেট ও সেশন প্রোটেকশন রাউট।

### ফেজ ২: মেস সেটআপ ও মেম্বার ডিরেক্টরি
- [ ] নতুন মেস তৈরির ফর্ম ও প্রাথমিক সেটিংস (মুদ্রা, ব্রেকফাস্ট মিল কাউন্ট)।
- [ ] মেম্বার ডিরেক্টরি CRUD (যোগ, সম্পাদন, নিষ্ক্রিয়করণ)।
- [ ] মেম্বার সার্চ ও ফিল্টারিং ব্যবস্থা।

### ফেজ ৩: মিল ট্র্যাকিং ও বাল্ক এন্ট্রি
- [ ] তারিখ ও মাসভিত্তিক ফিল্টারিং।
- [ ] ডেসকটপ ফ্রেন্ডলি বাল্ক মিল এন্ট্রি গ্রিড।
- [ ] ডুপ্লিকেট এন্ট্রি প্রতিরোধ ও অডিট লগ ট্র্যাকিং।

### ফেজ ৪: বাজার শিডিউলার
- [ ] মাসিক বাজার ক্যালেন্ডার।
- [ ] মেম্বার অ্যাসাইনমেন্ট, সোয়াপ ও স্ট্যাটাস আপডেট ('assigned', 'completed')।

### ফেজ ৫: অ্যাকাউন্টস ও মান্থলি সেটলমেন্ট
- [ ] ডিপোজিট ও খরচের ভাউচার এন্ট্রি (ক্যাটেগরি ও ভাউচার আপলোড সহ)।
- [ ] অটোমেটিক মিল রেট ক্যালকুলেটর।
- [ ] মান্থলি ক্লোজিং ও লক উইজার্ড।

### ফেজ ৬: রিপোর্ট জেনারেশন ও এক্সপোর্ট
- [ ] মাসিক মেস সামারি রিপোর্ট।
- [ ] ইন্ডিভিজুয়াল মেম্বার স্টেটমেন্ট।
- [ ] বাংলা ফন্ট সাপোর্টেড PDF এবং ইমেজ (PNG) এক্সপোর্ট।
