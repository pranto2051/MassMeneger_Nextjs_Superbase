# 03 — Web Security, Auth & RLS (Mess Website)

## 1. ওয়েব নিরাপত্তা নীতিমালা
1. **HTTP-only Cookies**: ব্রাউজার সেশনে অথেন্টিকেশন টোকেন রাখার জন্য সিকিউর HTTP-only কুকি ব্যবহার করা হবে, যাতে XSS অ্যাটাক থেকে নিরাপদ থাকা যায়।
2. **Row Level Security (RLS)**: প্রতিটি ডাটাবেজ টেবিলে RLS সক্রিয় থাকবে। মেস A-এর কোনো ইউজার কখনোই মেস B-এর ডেটা দেখতে বা পরিবর্তন করতে পারবে না।
3. **সার্ভিস রোল সিকিউরিটি**: `SUPABASE_SERVICE_ROLE_KEY` কখনোই ব্রাউজার বান্ডেলে যাবে না। শুধুমাত্র সার্ভার-সাইড ব্যাকগ্রাউন্ড ক্রন জব বা অ্যানোলিটিক্সে এটি নিয়ন্ত্রিতভাবে ব্যবহার হতে পারে।

## 3. মেম্বারদের গোপনীয়তা ও সুরক্ষা
- মেসের মেম্বার ডিরেক্টরিতে ফোন নম্বর ও হোয়াটসঅ্যাপ লিংক শুধুমাত্র ওই মেসের ভেরিফায়েড মেম্বাররাই দেখতে পারবে।
- মেম্বারের ব্যক্তিগত নোট, পেমেন্ট রেফারেন্স এবং অডিট লগ সাধারণ মেম্বারদের থেকে আড়াল রাখতে হবে।
