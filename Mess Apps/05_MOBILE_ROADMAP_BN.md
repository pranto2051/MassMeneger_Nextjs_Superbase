# 05 — Implementation Roadmap & Build Guide (Mess Apps)

## ফেজভিত্তিক মোবাইল অ্যাপ রোডম্যাপ (✅ ১০০% সম্পন্ন)

### ফেজ ১: প্রজেক্ট সেটআপ ও আর্কিটেকচার
- [x] Expo (React Native) + TypeScript প্রজেক্ট সফলভাবে প্রস্তুত ও ভেরিফাইড।
- [x] Supabase JS Client (`@supabase/supabase-js`) ও SecureStore অ্যাডাপ্টার ইন্টিগ্রেশন।
- [x] প্ল্যাটফর্ম ফলব্যাক ও অফলাইন-ফার্স্ট মক ডেটা আর্কিটেকচার।

### ফেজ ২: নেভিগেশন ও লিকুইড গ্লাস থিম ফ্রেমওয়ার্ক
- [x] ৫টি বটম ট্যাব (Home, Meals, Market, Accounts, Profile) সমৃদ্ধ কাস্টম ফ্রস্টেড গ্লাস বার।
- [x] ডার্ক গ্লাস (Dark Mode) ও লাইট গ্লাস (Light Mode) থিম সুইচিং।
- [x] Safe area insets (`react-native-safe-area-context`) ও রেসপনসিভ টাচ টার্গেটস।

### ফেজ ৩: হোম ও মেম্বার ড্যাশবোর্ড
- [x] ব্যক্তিগত পাসবুক হিরো কার্ড (সারপ্লাস/বকেয়া স্ট্যাটাস, জমা, মিল খরচ, ফিক্সড চার্জ)।
- [x] আজকের ও আগামীকালের মিল স্ট্যাটাস ও ইনস্ট্যান্ট কাউন্টার উইজেট।
- [x] আজকের বাজার দায়িত্বপ্রাপ্ত সদস্যের কার্ড ও ১-ক্লিক ফোন কল এবং হোয়াটসঅ্যাপ বাটন।
- [x] কুইক অ্যাকশন বাটনস ও মেসের সার্বিক KPI মেট্রিক্স।

### ফেজ ৪: মিল ট্র্যাকিং ও ইনপুট মোডস
- [x] ডেট নেভিগেটর বার (পূর্ববর্তী দিন, পরবর্তী দিন ও 'আজ' শর্টকাট)।
- [x] **ডিরেক্ট মিল ইনপুট মোড (Direct Total)**: সরাসরি `[ - ]` `[ Count ]` `[ + ]` এবং কুইক চিপস (`০ (অফ)`, `১ টি`, `২ টি`, `৩ টি`)।
- [x] **বেলা ভিত্তিক মোড (Detailed Shifts)**: সেটিংস অনুযায়ী সকালের নাশতা, দুপুর ও রাতের খাবার আলাদা কাউন্টার।
- [x] বাল্ক অ্যাকশন টুলবার (সবার মিল এক ক্লিকে ১ বা ০ করা)।
- [x] হ্যাপটিক ফিডব্যাক ও অটোমেটিক সেভ টোস্ট।

### ফেজ ৫: বাজার শিডিউল, সোয়াপ ও মেমো আপলোড
- [x] চলতি মাসের বাজার রোস্টার টাইমলাইন ও স্ট্যাটাস ট্র্যাকার (`assigned`, `completed`, `swapped`)।
- [x] **বাজার দায়িত্ব অদল-বদল (Duty Swap)**: যেকোনো ২ জন সদস্যের শিডিউল সোয়াপ করার বটম শিট মডাল।
- [x] **অটো রোস্টার জেনারেটর**: দিন সংখ্যা নির্ধারণ করে সকল সক্রিয় মেম্বারদের রোটেটিভ শিডিউল তৈরি।
- [x] ক্যামেরা ও গ্যালারি দিয়ে মেমোর ছবি আপলোড (`expo-image-picker`) ও প্রিভিউ।

### ফেজ ৬: মান্থলি সেটলমেন্ট, পাসবুক ও ডিজিটাল অডিট স্লিপ
- [x] জিরো-গার্ড সহ স্বয়ংক্রিয় ডায়নামিক মিল রেট ক্যালকুলেটর (`Eligible Expenses / Total Meals`)।
- [x] মাথাপিছু ফিক্সড খরচ বণ্টন ও মেম্বার ব্যালেন্স শিট।
- [x] **ডিজিটাল অডিট স্লিপ মডাল (Member Audit Slip)**: পূর্ণাঙ্গ গাণিতিক হিসাব বিবরণী ও নেটিভ শেয়ার ডায়ালগ (`expo-sharing` / `Share.share`)।
- [x] জমা (Deposits) ও খরচ (Expenses) ম্যানেজমেন্ট ও ডিলিট অপশন।
- [x] সেটলমেন্ট পিরিয়ড অডিট লক ও আনলক ফিচার।

### ফেজ ৭: মেম্বার ডিরেক্টরি ও মেস সেটিংস
- [x] সার্চেবল মেম্বার ডিরেক্টরি ও ১-ট্যাপ কল এবং হোয়াটসঅ্যাপ লিঙ্কিং।
- [x] নতুন মেম্বার রেজিস্ট্রেশন মডাল (`AddMemberModal`)।
- [x] মেস সেটিংস: নাম, মিল ইনপুট পদ্ধতি সুইচ, নাশতা/দুপুর/রাত টগল ও পয়েন্ট কনফিগারেশন।
- [x] অ্যাক্টিভ প্রোফাইল সুইচার (`ActiveMemberPickerModal`)।

---

## 🚀 মোবাইল অ্যাপ চালু করার নিয়ম

```bash
cd "Mess Apps"
npm install
npm run start
```

- **Android এ দেখতে**: কীবোর্ডে `a` চাপুন বা `npm run android`
- **iOS এ দেখতে**: কীবোর্ডে `i` চাপুন বা `npm run ios`
- **ব্রাউজারে দেখতে**: কীবোর্ডে `w` চাপুন বা `npm run web`
